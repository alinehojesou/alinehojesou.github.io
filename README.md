# Portfólio — Aline da Silva

Site estático bilíngue (EN em `/`, PT-BR em `/pt/`), pronto para o GitHub Pages.

## Publicar
1. No GitHub, crie um repositório **público** chamado `alinehojesou.github.io`.
2. Em "uploading an existing file", arraste **todo o conteúdo desta pasta** (não a pasta em si) e clique em Commit.
3. Em Settings → Pages, confirme: Source = "Deploy from a branch", branch `main`, pasta `/ (root)`.
4. Em 1–2 minutos o site abre em https://alinehojesou.github.io/

## Contato (um arquivo só)
Edite `assets/js/config.js`:
- `email`: o endereço público que aparece no site e nos links de email.
- `form`: endpoint de um serviço de formulário (ex.: Formspree). Vazio = o formulário abre o app de email do visitante.

## Trocar imagens
As imagens ficam em `assets/img/` (`cases/`, `work/`, `logos/`). Substitua mantendo o mesmo nome de arquivo.
