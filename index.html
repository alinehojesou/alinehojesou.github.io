The briefThe systemThe buildBehind the scenesThe result

CommerceIQ ran on WordPress with rigid HTML themes — even reordering a section meant a developer and a multi-day ticket. I planned the site as a living system and rebuilt it across three generations, each one cutting dev dependency and raising the design bar.

Three generations, one system

Rather than a single redesign, I planned the site as a living system that improves every quarter — each generation trading dev dependency for autonomy.

The build

Designed and built across three platforms, every breakpoint and animation by hand, on a reusable component system that made the V1 → V2 migration nearly effortless: update the components, and most pages updated with them.

  • Rebrand + AIHTML/CSS · Claude
